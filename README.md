# RAG-Based Document Question Answering System

## 📌 Project Overview

This project implements a **Retrieval-Augmented Generation (RAG)** based Question Answering system using Python. The system allows users to ask questions from their documents and retrieves relevant information using semantic search before generating accurate responses.

The project combines **document processing, embeddings, vector databases, and Large Language Models (LLMs)** to build an intelligent document assistant.

---

## 🎯 Objective

The main objective of this project is to develop a system that can:

- Extract information from user-provided documents
- Convert documents into searchable vector representations
- Retrieve relevant context using semantic similarity
- Generate accurate answers based on retrieved information

## 🚀 Features

✅ PDF document loading  
✅ Text extraction and preprocessing  
✅ Document chunking using text splitters  
✅ Semantic embeddings generation  
✅ Vector storage using ChromaDB  
✅ Similarity-based document retrieval  
✅ Context-aware question answering
